ArkType contract pattern

The small set of patterns used to define, infer, validate, and test every quiz contract.

Define

const Input = type({
  count: "1 <= number.integer <= 50"
})

Infer

type Input =
  typeof Input.infer

Validate

const result = Input(data)

if (result instanceof type.errors) {
  throw Error(result.summary)
}

Test

expect(Input(badData))
  .toBeInstanceOf(type.errors)
