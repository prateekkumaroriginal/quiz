The shortest safe path from an HTTP request to quiz business logic.

Handler pattern

let body: unknown

try {
  body = await context.req.json()
} catch {
  return context.json(invalidRequest("Invalid JSON"), 400)
}

const input = GetQuestionsInput(body)

if (input instanceof type.errors) {
  return context.json(invalidRequest(input.summary), 400)
}

// Safe to use input.category and input.count

Boundary checklist

  • Keep external data as unknown.
  • Handle malformed JSON separately from a wrong data shape.
  • Return before business logic when validation fails.
  • Give error responses their own shared schema.
  • Test the route with real Request and Response objects.
