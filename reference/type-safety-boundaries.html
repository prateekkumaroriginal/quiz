Type-safety boundaries

A quick test for deciding where the quiz system needs static types, runtime validation, or both.

Static type

  • Checked by TypeScript
  • Protects compiled source
  • Erased from JavaScript
  • Cannot inspect JSON

Runtime schema

  • Runs as JavaScript
  • Accepts unknown data
  • Returns data or errors
  • Can infer a static type

Boundary rule

If data comes from a caller, network, file, environment variable, or database, treat it as unknown until a runtime schema proves its shape.

Quiz SDK placement

Server request

Validate query parameters before business logic.

Server response

Validate during development and contract tests.

SDK options

Validate before sending the HTTP request.

SDK response

Validate parsed JSON before returning questions.
