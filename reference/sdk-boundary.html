SDK boundary

Validate before sending and after receiving. Return only contracted values.

Client flow

Validate inputor INVALID_INPUT
→
Fetch and parsebody is unknown
→
Validate outputor INVALID_RESPONSE

Success pattern

const validInput = GetQuestionsInput(input)
if (validInput instanceof type.errors) {
  throw new QuizClientError("INVALID_INPUT", validInput.summary)
}

const response = await fetch(url, request)
const body: unknown = await response.json()
const output = GetQuestionsOutput(body)

if (output instanceof type.errors) {
  throw new QuizClientError("INVALID_RESPONSE", output.summary)
}

return output.questions

Error map

  • INVALID_INPUT means the request never leaves the SDK.
  • API_ERROR means the server returned a non-success status.
  • INVALID_RESPONSE means a success body broke the output contract.
