# Teaching notes

- The learner has used Zod before.
- Use ArkType for the quiz API contract and boundary validation.
- Explain ArkType concepts by connecting them to the learner's existing Zod mental model when useful.
- Use a hands-on teaching loop. Write and run the tests, then tell the learner which behavior each new test specifies. Have the learner write all production and contract implementation code. Give a small goal, constraints, and commands; review their attempt and respond with progressively stronger hints. Do not write implementation code unless the learner explicitly asks for it.
- Explain the reason for every requested command, file, field, and design choice, including what problem it prevents.
- Name each ArkType runtime schema and its inferred TypeScript type identically, relying on TypeScript's separate value and type namespaces.
